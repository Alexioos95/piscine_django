Groupement de petits exercices, afin de découvrir Python et son Framekwork Web Django.

Chaque module se concentre sur une thématique:

0. Initiation - Shell, HTML et CSS
1. Orientée Objet - Python
2. Programmation - Python
3. Base de Django - Template, formulaires et routing
4. Bibliothèques - Python
5. SQL - Requêtes et ORM
6. Avancé - Views génériques
7. Final - Chat en JQuery
8. Sessions - Comptes et connexion
